Infinikey IME is an open-source, programmable soft keyboard and input environment for Android, designed for software developers, terminal operators, power users, and touch typists.

WHAT IS INFINIKEY?
Infinikey transforms the mobile keyboard from a static typing surface into a fully configurable, stateful input environment. It combines declarative layouts, multi-step macros, accessory panels, interactive overlays, and visual themes into a desktop-grade mobile input system.

WHY USE INFINIKEY?
• Desktop-Class Precision: Access dedicated Function keys (F1–F12), multi-modifier states (Shift, Ctrl, Alt, Super, Meta), and unbuffered shell keycode output for Termux, SSH, VNC, and RDP sessions.
• Maximize Screen Geometry: Docked and split screen modes repurpose unused screen deadspace into dynamic accessory control panels.
• Privacy-First & Offline: 100% offline with zero network permissions, zero telemetry, zero analytics, and zero ads.

HOW IT WORKS & KEY FEATURES:
• Declarative JSON Engine: Layout geometry, key ratios, and touch actions (press, long-press, directional swipes) are defined in clean, human-readable JSON files.
• Visual WYSIWYG Editor: Real-time visual layout editor with drag-and-drop key reordering, action type assignment, and instant property tweaking.
• 5 Screen Docking Modes: Full-width docked, Split thumb-cluster, Left-docked, Right-docked, and Floating window with persistent position memory.
• Accessory Area System: Embed secondary control surfaces (Navigation pads, Numpads, Macro grids, Media controls, App launchers) or custom text into screen margins.
• Keystroke Macro System: Record and replay multi-step keystroke sequences (M1–M10) with touch-and-hold recording.
• Power-User Tools & Audio: 30-item persistent clipboard history, 5x5 app launcher grid with keycap icon rendering, spacebar trackpad cursor navigation, and Mechvibes mechanical switch audio packs.
